🔐 LockNote

Una aplicación de gestión de contraseñas que cualquier persona puede usar con facilidad y tranquilidad.

📖 Ver cómo usarla

¡Le damos la bienvenida!

«LockNote» ofrece un alto nivel de seguridad y comodidad, y al mismo tiempo tiene pantallas sencillas y fáciles de entender, sin funciones innecesarias. Así, personas de todas las edades pueden usarla con tranquilidad.

La aplicación no muestra ningún anuncio. Puede probarla gratis durante el primer mes y, después, usarla con el plan Premium por 100 yenes al mes (impuestos incluidos). Antes de la prueba o después de cancelar, siempre puede ver, copiar y exportar los datos que haya guardado. Además, mejoramos la aplicación de forma continua a partir de sus comentarios, para que sea cada vez más cómoda y segura. También contamos con un buen servicio de asistencia, para que pueda usarla con total tranquilidad.
